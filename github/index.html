Abstract

บทคัดย่อ

โครงงานนี้นำเสนอการพัฒนาระบบรดน้ำต้นไม้อัตโนมัติ “Baby Tree” โดยใช้บอร์ด Arduino Uno R4 WiFi ร่วมกับเซนเซอร์วัดความชื้นในดิน รีเลย์ และปั๊มน้ำ บอร์ดจะอ่านค่าความชื้นทุก 5 วินาทีและแปลงค่าดิบจาก ADC เป็นเปอร์เซ็นต์ เมื่อเปิดโหมดอัตโนมัติและความชื้นต่ำกว่า 30% ระบบจะเปิดปั๊มครั้งละ 2 วินาที จากนั้นพัก 15 วินาทีเพื่อให้น้ำซึมลงดินก่อนวัดค่าใหม่ เพื่อป้องกันการรดน้ำมากเกินไป

ด้านความปลอดภัย ระบบจำกัดการเปิดปั๊มไว้ไม่เกิน 5 ครั้งต่อชั่วโมง หากรดครบแล้วดินยังแห้ง ระบบจะล็อกตัวเองและแจ้งเตือนให้ตรวจสอบน้ำในถังหรือสายยาง และมี Watchdog Timer รีเซ็ตบอร์ดเมื่อโปรแกรมค้าง ค่าความชื้นและสถานะจะแสดงบนจอ LCD 16×2 ที่ตัวเครื่อง

การควบคุมจากระยะไกลใช้โปรโตคอล MQTT ผ่าน broker สาธารณะ HiveMQ บอร์ดส่งสถานะในรูปแบบ JSON ไปยังเว็บไซต์ และรับคำสั่งรดน้ำหรือเปิด/ปิดโหมดอัตโนมัติจากเว็บ ส่วนเว็บไซต์เขียนด้วย HTML และ JavaScript เชื่อมต่อ broker ผ่าน WebSocket แสดงความชื้น สถานะปั๊ม จำนวนครั้งที่รดในชั่วโมงนั้น และประวัติการรดน้ำ พร้อมตรวจจับได้ว่าบอร์ดออฟไลน์ด้วย Last Will ของ MQTT ผลที่ได้คือระบบที่ดูแลต้นไม้ได้เองโดยใช้น้ำเท่าที่จำเป็น และผู้ใช้ติดตามหรือสั่งการได้ทุกที่ที่มีอินเทอร์เน็ต

คำสำคัญ: Arduino Uno R4 WiFi, ความชื้นในดิน, รดน้ำอัตโนมัติ, MQTT, Internet of Things

English. Baby Tree is an automatic plant watering system built on an Arduino Uno R4 WiFi with a soil moisture sensor, relay and water pump. The board reads soil moisture every 5 seconds; in auto mode it runs the pump for 2 seconds whenever moisture drops below 30%, then waits 15 seconds for the water to soak in. Pumping is capped at 5 times per hour, after which the board locks and asks the user to check the water supply, and a watchdog timer recovers the board if it hangs. The board publishes its status as JSON over MQTT (HiveMQ public broker) and accepts commands from a web dashboard that connects over WebSocket, so the plant can be monitored and watered from anywhere.

Keywords: Arduino, soil moisture, automatic irrigation, MQTT, IoT

บอร์ดเป็นผู้ตัดสินใจทั้งหมด เว็บแค่ส่งคำสั่ง ถ้าเน็ตหลุด ต้นไม้ก็ยังได้รับการดูแล

→
PUMPINGปั๊มทำงาน 2 วินาที
→
SOAKINGรอน้ำซึม 15 วินาที แล้วกลับ IDLE
⇢
LOCKEDรดครบ 5 ครั้ง/ชม. · ปลดล็อกเมื่อครบชั่วโมง

ขั้นตอนการทำงาน

  1. เมื่อเปิดเครื่อง บอร์ดเชื่อม WiFi และ MQTT ตั้ง Last Will เป็น 0 แล้วประกาศ online = 1
  2. ทุก 5 วินาที บอร์ดจ่ายไฟให้เซนเซอร์ อ่านค่า A1 แปลงเป็น % แล้วอัปเดตจอ LCD และส่ง JSON ไปที่ /status
  3. เว็บรับ JSON มาแสดงเป็นหน้าตาต้นไม้ (สดใส · ปกติ · กระหายน้ำ · ดินแห้งมาก) ตามระดับความชื้น
  4. เมื่อผู้ใช้กด “ให้น้ำเลย” เว็บส่ง pump ไปที่ /cmd บอร์ดตรวจว่าอยู่ใน IDLE และยังไม่ครบโควตา แล้วจึงเปิดปั๊ม
  5. ถ้าไม่มีสถานะใหม่เกิน 20 วินาที หรือได้รับ online = 0 เว็บจะแสดงว่าบอร์ดออฟไลน์และปิดปุ่มควบคุม

int readRaw() {
  digitalWrite(SENSOR_POWER, HIGH);
  delay(10);
  int v = analogRead(SENSOR_PIN);
  digitalWrite(SENSOR_POWER, LOW);
  return v;
}

int toPercent(int r) {
  return constrain(map(r, RAW_DRY, RAW_WET,
                       0, 100), 0, 100);
}

เริ่มรดน้ำอย่างปลอดภัย

ใช้ร่วมกันทั้งโหมดอัตโนมัติ ปุ่มบนเว็บ และ Serial

bool startPump() {
  if (state != IDLE) return false;
  if (pumpsThisHour >= MAX_PUMPS_PER_HOUR)
    return false;
  pump(true);
  pumpStart = millis();
  pumpsThisHour++;
  state = PUMPING;
  refresh();   // LCD + MQTT status
  return true;
}

ส่งสถานะผ่าน MQTT

ส่งแบบ retained เว็บที่เพิ่งเปิดจะได้ค่าล่าสุดทันที

snprintf(json, sizeof(json),
  "{\"moisture\":%d,\"raw\":%d,"
  "\"state\":\"%s\",\"auto\":%s,"
  "\"pumps\":%d}", ...);
mqtt.beginMessage(TOPIC_STATUS, true);
mqtt.print(json);
mqtt.endMessage();

ฝั่งเว็บ (JavaScript)

เชื่อม broker ผ่าน WebSocket แล้ว subscribe สถานะ

const client = mqtt.connect(
  "wss://broker.hivemq.com:8884/mqtt");

client.on("connect", () => {
  client.subscribe([t.status, t.online]);
  send("status");
});

$("water-button").onclick =
  () => send("pump");
