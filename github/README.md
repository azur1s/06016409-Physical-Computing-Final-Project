# Baby Tree — GitHub Pages site

Project website (abstract, hardware, system, code, team) for the Baby Tree plant watering project.

- `index.html` — the project page (the control app in `../web` is separate and not part of this site)

## Before publishing

Fill in the `TODO` blocks in `index.html`: team names / student IDs, and the YouTube embed for the demo video.

## Publishing

GitHub Pages can only serve from the repo root or `/docs`, so push the contents of this folder to its own repo:

1. Create a new public repo, e.g. `baby-tree`.
2. Push the files in this folder to its `main` branch.
3. Repo **Settings → Pages → Build and deployment**: Source `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. The site appears at `https://<username>.github.io/baby-tree/`.
